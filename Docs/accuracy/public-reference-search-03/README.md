# Public CS-50 reference qualification: bounded third pass

**No new recording qualified as a named factory-preset benchmark with known global controls and original MIDI or measured gate times.** Eight targeted web queries were checked on 18 October 2026, followed by primary creator-page metadata inspection. No audio/video was acquired, no creator was contacted, and no purchase, rendering or fitting occurred.

The current [active-source summary](../ACTIVE-SOURCES.md), the archive's first candidate manifest, and both previous source-search notes were read first. Synth4ever, AutomaticGainsay, Doctor Mix, Whitmore, PTK, AMAZONA, Synth Sounds and the Haible/LesIndes examples are therefore **existing leads**, not newly discovered independent evidence.

The [VSE page](https://www.vintagesynth.com/yamaha/cs-50) was used only to locate its two creator links, not as authority for sound settings or technical specifications. SynthMania's own [CS-50 site search](https://synthmania.com/?s=CS-50) returned no results during this check. Targeted AnalogAudio1 and Gattobus queries did not yield a relevant creator recording with stronger metadata. These are bounded search outcomes, not claims that no such recording exists anywhere.

A useful next acquisition step would be an on-service visual audit of AutomaticGainsay's already known preset video: first establish a named preset with a legible stationary performance-control bank, then inspect isolated held notes and visible key-up events. Until that evidence exists, no transcription should be called original MIDI and no recording should enter a controlled fidelity score. A clear hand gesture alone still does not reveal internal calibration, touch pressure or sample-accurate gate timing.
