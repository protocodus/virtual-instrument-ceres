# Ceres CPU steps — 2026-11-05

Ceres 1.1.5 does 6–7.5% fewer instructions than 1.1.4 for bit-identical audio. The baseline is `9c021cd` (1.1.4). Five steps, one mechanism per commit, each chosen from a callgrind profile of `Tools/callgrind_presets.cpp` and each kept only if the audio stayed bit for bit unchanged.

## Changes

1. **The cutoff rows' diode log1p carried along small steps** (`6ea4f8a`). The `CutoffBus` Newton solve recomputed `log1p(I/Is)` at every new current; between steps I moves by under 1e-5 of Is+I on nearly every factory-preset step, so the term is carried as log1p(I/Is) + r − r²/2 + r³/3 with r = (I′−I)/(Is+I) (series error under 3e-21), with an exact `log1p` every eighth hop so rounding cannot accumulate. glibc's `log1p` fell from 3.4% of the 4-voice workload to 0.5%.
2. **The cutoff exp2's table index rounded with the shifter** (`476591b`). `rint(32x)` is a dozen instructions at the baseline x86-64 ISA and a call under `-fno-builtin`; adding and subtracting 1.5·2⁵² rounds identically in round-to-nearest for |32x| < 2⁵¹.
3. **Each filter pair settled and stored in its two-double lanes** (`92b173e`). `begin()`, `settledLow()` and `end()` of the paired OTA solve ran scalar per board after the lane iterations; they now run on both lanes, each lane in the scalar operation order, with only an unconverged lane's tanh left scalar.
4. **The PWM sine skipped while the pulse is muted or PWM depth is zero** (`dfbd156`). The sine reaches only the pulse comparator's level, where a zero depth adds a zero that the oscillator's clamp removes. The PWM phase runs on.
5. **The ring carrier network's rows in two-double lanes** (`8dea19c`). The free-running carrier's 4×4 network sums rows 0–1 and 2–3 in lanes from a row-pair copy of its inverse.

Nothing user-facing changed: voices, 1x/2x/4x, latency, the noise, ring and EXT paths, every free-running state and every parameter are as in 1.1.4. No compiler flag changed.

Tried and dropped: a division-free carried `CutoffBus` step (no measurable time change, +0.2% instructions); the pitch `exp2` through `fastExp2` (no measurable time change, and it would move the oscillator's phase bits); a ring wet path idle at mix 0 (−6.6% instructions, but `Ceres.ring_carrier_circuit_contracts` and the design keep the carrier network running at mix 0, and it would need a listening set).

`Tests/CpuParityDriver.cpp` compiled against both cores, plus a copy writing float64 instead of float32, over the 439,296-sample protocol stream (all factory presets × {1,4,16} voices × {1,2,4}x, four host rates under live controls, three long scenes):
