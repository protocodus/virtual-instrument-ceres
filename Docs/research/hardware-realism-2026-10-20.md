# Ceres: hardware realism research (2026-10-20)

Ceres models the Yamaha CS-50. This pass read the primary sources again,
looking for hardware behaviour the engine still omits or simplifies. The engine
already carries a deep circuit model (VCO conditioning, IG00156 filters,
capacitor envelopes, BRILLIANCE/RESONANCE buses, PRA ring modulator, SUB
routing, Sustain I/II), so these items target what is left.

## Sources

- **Guide**: Yamaha CS Series Synthesizer Servicing Guide,
  <https://rcarchives.com/m/YamahaCSSeriesSynthesizerServicingGuidePOSTED.pdf>.
  Page numbers are printed page / PDF page.
- **SM1, SM2**: Yamaha CS-50 Service Manual 1 of 2 and 2 of 2,
  <https://bama.edebris.com/manuals/yamaha/cs-50/>.
- File:line references are to `Source/DSP/ceres.cpp` at `35c1aaf`, before the change. Items 1–5 shipped in 0.3.0.

## Findings

| # | Hardware behaviour | Source | Ceres today | Proposal | Verdict |
|---|---|---|---|---|---|
| 1 | **Portamento and glissando.** Panel 3 has a PORTAMENTO/GLISSANDO switch and a time lever. In the KAS circuit, the YM26700 glissando counter steps the key code one semitone at a time from the previous key to the new one, at a rate set by a clock VCO. In GLISSANDO the steps go straight to the sample-hold. In PORTAMENTO they first pass an RC integrator (470 kΩ, 3.3 MΩ, 1 µF) that turns the staircase into a glide. The integrator works on the key voltage, which is linear in Hz. With SUSTAIN II on, a note released mid-glide keeps gliding while it decays. | Guide printed p.6 (panel 3); pp.23–25 / PDF 32–34 (glissando circuit, integrating gate, comparator table); SM2 p.3 (KAS: IC24 clock oscillator, VR4 B-100k) | No glide of any kind. Key pitch jumps on note-on (ceres.cpp:951, 805, 824). | Add `glide_mode` (0 off, 1 portamento, 2 glissando) and `glide_rate` (semitones/s). Model a per-voice semitone counter driven by the assigner key, plus a Hz-domain integrator in portamento mode. The integrator feeds the shared key CV to both the VCO and the filters. Sustain I holds the pitch at key release; Sustain II keeps gliding. | **Implement.** The topology comes from the sources. Counter rate is an engineering control: IC24's type and its PS→Hz law are not printed. |
| 2 | **Same-key channel reuse.** The key assigner only overwrites a channel whose code differs from the pressed key and whose key is up. If a released channel still holds the pressed key's code, that channel is re-keyed, so a repeated note retriggers its own board. | Guide pp.16–19 / PDF 25–28 (key assigner: gate control, "Depressing a new key") | A repeated note takes an idle board first, then the quietest released board (ceres.cpp:933–943). The same note can stack on several boards. | Before the idle/quietest search, reuse a released, non-pedal board that already holds that note. | **Implement.** Changes which board sounds and so audibly changes repeated-note tails. |
| 3 | **Touch BRILLIANCE has unequal HP/LP coupling.** R7 feeds TBR into each LP node through 47 kΩ and each HP node through 150 kΩ, the same split as SUB. | SM1 p.14 / PDF 8 (R7 cutoff mixing, TBR pin 69) | `pressure_filter` adds the same octaves to HP and LP (ceres.cpp:826, 831). | The HP depth becomes `(.7/.65)*(47/150) = 0.3374` × the LP depth. This is the ratio already used for the SUB route (ceres.cpp:23). | **Implement.** Same resistor ratio and slopes as the accepted SUB correction. |
| 4 | **Touch-controlled wah.** The SUB board's level-control amplifier II scales the SUB signal by the touch voltage and sends it (FD → R7 `VCF`, pin 70) into the cutoff nodes through 47 kΩ LP / 150 kΩ HP. Panel 2's touch section makes the sub-oscillator effect deeper as the key goes down. | Guide pp.55–56 / PDF 63–65 (touch response, level control amplifier); printed p.5 (panel 2); SM1 p.14 (R7 pin 70) | Touch reaches vibrato only. There is no touch→SUB→VCF route (ceres.cpp:825–832). | Add `pressure_wah`: LP octaves of the selected SUB waveform per unit touch, with HP at 0.3374×. | **Implement.** |
| 5 | **Touch vibrato rises in pitch.** Level-control amplifier I (touch → SUB → vibrato) is trimmed so a 0 V-centred SUB input comes out centred on +0.5 V. Yamaha says this makes the vibrato "more natural". The SUB signal is 3 Vpp, so the offset is +1/3 of its peak. | Guide p.56 / PDF 65 (VR4 trim note); p.55 (SUB fixed at 3 Vpp) | Touch vibrato is symmetric around the key pitch (ceres.cpp:803–804). | Touch vibrato uses `(SUB + 1/3)`, scaled by touch. The panel VCO lever path stays symmetric. | **Implement.** Assumes the offset scales with the touch gain, because at zero touch the amplifier passes nothing. That reading is an inference. |
| 6 | **Touch LEVEL adds into the common VCA node.** R7 sums SUB (120 kΩ), LEVEL (270 kΩ) and touch LEVEL (150 kΩ) currents into LC. Touch is trimmed to 6.0 V at full depth. Full touch therefore adds (6/150k)/(10/270k) = 1.08× the full-LEVEL current. | SM1 p.14 (R7 LC matrix); Guide p.55 (6.0 V touch calibration) | `pressure_volume` multiplies the gain by `1−depth*(1−touch)`, so with no touch it attenuates (ceres.cpp:849–850). | Make it additive: `ampLevel + 1.08*depth*touch`. | **Implemented** after the owner chose the hardware law (2026-10-20). The IG00151's headroom above 10 V LEVEL is still unknown. |
| 7 | **No voice stealing.** The assigner stores at most four codes. A fifth key is ignored until a channel is released. | Guide p.19 / PDF 28 (timing chart: "A5 note is not stored") | The oldest held board is stolen (ceres.cpp:944–946). | Ignore notes once every board is held. | **Not implemented, needs your call.** It drops notes in a DAW, and it interacts with the 1–16 voice option and the note-reuse contracts. |
| 8 | **SUB speed range is 0.8–50 Hz,** calibrated at 0.8 / 6.7 / 50 Hz for 0 / 5 / 10 V (exponential). | Guide p.55 / PDF 63 | `lfo_rate` accepts 0.05–100 Hz (ceres.cpp:84). | Narrow the range, or map a hardware lever. | **Skipped.** Narrowing breaks saved patches. The wider engineering range contains the hardware range, and an adapter can map a lever onto it. |
| 9 | **Key-voltage D/A ladder intonation.** Notes come from an octave R-2R ladder and a 12-tap note ladder (eleven 100 Ω series, 29.94 kΩ shunt). The ladder only approximates equal temperament, so real units may have small per-note tuning offsets. | SM2 p.3 (KAS note/octave ladder networks); Guide p.23 | Exact equal temperament (ceres.cpp:805). | Compute per-semitone deviations from the ladder. | **Skipped.** The scan does not show where the shunt bus and the IC3 buffer return, so the deviations cannot be computed without guessing the topology. |
| 10 | **Audio noise is hard-limited.** A zener source is driven into a limiter op-amp at saturation (30 Vpp), giving "white noise of constant amplitude". It is then trimmed to 3 Vpp. | Guide p.32 / PDF 41 | Uniform white random source (ceres.cpp:757). | Model the noise as clipped (near-binary) noise. | **Skipped.** The spectrum stays white. Only the amplitude distribution changes, which is barely audible after filtering, and the zener level and limiter gain are not given. |
| 11 | **EXT sub-oscillator input.** Panel 3's FUNCTION switch can take an external audio signal as the modulation source. | Guide p.6; p.55 (EXT preamplifier) | Not implemented (README Known gaps). | An external modulation input. | **Skipped.** `Synth` has no audio input. This belongs to an adapter that offers a sidechain. |

## Already faithful (checked, no change)

- PWM: the PW lever spans 50–90 %, PWM gives ±40 %, and duty saturates near 99 % (Guide p.31). These match `pulse_width`, `pwm_depth` .4 and the `.01..0.99` clamp.
- PITCH: the ladder reference runs 3–6 V around 4 V, which is −498/+702 cents. This matches `tune_cents` −500..+700.
- The ring trigger fires on "any KEY-ON signal" (Guide p.19). This matches the physical-key ledger.
- Power-on key code is C4 in every channel (Guide p.17). Board reset uses note 60.
